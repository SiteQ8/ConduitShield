OT Playbook — Unauthorized PLC Write
1
Isolate: Block source IP at zone firewall. Do NOT power cycle the PLC — verify process state first.
2
Verify: Compare current PLC program against golden backup. Check for logic modifications or parameter changes.
3
Preserve: Capture network traffic, PLC program state, and all access logs. Maintain chain of custody.
4
Assess: Determine if process was affected. Engage operations team to verify physical process is safe.
5
Restore: If compromised, restore from verified backup. Re-enable monitoring before returning to service.
6
Report: Notify CISO, plant manager, and regulators if required. Document timeline and lessons learned.
