OT Playbook — Unauthorized PLC Write
1
Isolate: Block source IP at zone firewall. Do NOT power cycle the PLC — verify process state first. ⚠ SAFETY GATE
2
Verify: Compare current PLC program against golden backup. Check for logic modifications or parameter changes.
3
Preserve: Capture PCAP, PLC state, access logs. Maintain chain of custody for forensic investigation.
4
Assess: Determine if physical process was affected. Engage operations to verify safety. ⚠ SAFETY GATE
5
Restore: If compromised, restore from verified backup. Re-enable monitoring before returning to service.
6
Report: Notify CISO, plant manager, regulators. Document timeline and lessons learned.
