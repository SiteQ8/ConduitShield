# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in ConduitShield, please report it responsibly:

1. **Do not** open a public GitHub issue for security vulnerabilities
2. Email: Site@hotmail.com with subject: `[SECURITY] ConduitShield`
3. Include: description, steps to reproduce, potential impact
4. You will receive acknowledgment within 48 hours

## Scope

This security policy applies to:
- The ConduitShield GUI dashboard (`docs/index.html`)
- All scripts and tools in this repository
- Documentation that may inadvertently expose sensitive patterns

## Supported Versions

| Version | Supported |
|---------|-----------|
| v1.0.x  | Yes       |

## Disclaimer

ConduitShield is a demonstration and reference platform. The demo data uses synthetic ICS/OT information. Never use demo credentials in production environments.
